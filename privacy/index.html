隐私政策

最后更新：2026-10-12　|　适用站点：blog.qingyi.dpdns.org

本站是一个个人技术博客。为了让页面正常显示、统计阅读量、支持评论与登录，会处理少量必要数据。本站不出售、不交换、不向第三方共享你的个人信息用于营销目的。

一句话概括：不追踪你、不用广告 Cookie；评论与登录只保存必要字段；阅读量只做去重计数。

一、我们收集什么

  • 访问日志：为统计阅读量与排查异常，边缘服务会记录请求路径、时间、User-Agent、以及不可逆的 IP 哈希（不保存原始 IP 明文）。
  • 评论：你提交的昵称（可匿名）、评论正文、时间；若你填写邮箱，仅用于展示 Gravatar 头像或回复通知（取决于功能开关）。
  • 账号：注册时提供的用户名、昵称、邮箱、密码哈希（PBKDF2-SHA256 加盐，本站无法还原你的明文密码）。
  • 本地存储：登录令牌（localStorage，键名前缀 shawn_ / xw_）与「本文已读过」标记（sessionStorage），用于保持登录态与阅读量幂等。

二、Cookie 的使用

  • session：登录后由服务端下发的会话标识（HttpOnly、SameSite=Lax、默认 8 小时过期），仅用于识别登录状态。
  • 本站不使用广告、画像或跨站追踪 Cookie；不接入第三方广告联盟。
  • 你可以在浏览器中随时清除 Cookie 与本地存储；清除后需要重新登录，阅读量去重标记也会重置。

三、数据用途与保存期限

  • 阅读量、访问统计：用于展示热门文章与站点健康度，聚合数据可长期保留。
  • 评论与账号：在内容存在期间保留；你可以联系站长要求删除你的评论或账号。
  • 审计与登录日志：用于安全排查与防滥用，保留较短周期后清理。

四、第三方服务

  • Cloudflare：提供 CDN、DNS 与边缘计算（页面与接口请求会经过其网络）。
  • GitHub Pages：静态资源托管来源。
  • 若页面嵌入外部资源（如视频、代码高亮库、评论头像服务），其提供方可能按自身隐私政策处理请求信息。

五、你的权利

  • 查询、更正你的账号资料；注销账号；删除你的评论。
  • 拒绝或撤回同意：不登录、不评论即可让本站几乎不保存与你相关的个性化数据。
  • 行使方式：在 关于我 页面找到联系方式，或通过页脚邮箱联系站长。

六、未成年人

本站面向成年技术读者，不针对未成年人设计；若监护人发现未成年人提交了个人信息，可联系站长删除。

七、政策更新

本政策如有更新，会修改本页顶部的「最后更新」日期并在站内提示；重大变更会在首页公告。

本页为通用模板，具体表述以站长最终确认为准；若你所在司法辖区有额外要求（如 GDPR/CCPA），请联系站长补充。
